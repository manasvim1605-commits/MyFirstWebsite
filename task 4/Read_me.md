## 📌 Project Overview
This project is a **complete responsive business website** built using HTML, CSS, and JavaScript. The website is designed to provide a modern, user-friendly interface for users to explore services, view business information, and contact the business. The project includes multiple pages, responsive design, accessibility features, and is deployed to a free hosting platform.

**Features Implemented:**
- Responsive layout with mobile-first approach
- Navigation across multiple pages
- Contact form with validation
- Optimized images and assets for faster performance
- Cross-browser compatibility
- Accessibility enhancements (ARIA attributes, semantic HTML)
- Deployed on [GitHub Pages / Netlify]

**Pages Included:**
- `index.html` – Home page
- `about.html` – About the business
- `services.html` – Services offered
- `contact.html` – Contact form

## 🎨 Design Decisions

* **Mobile-First Approach:** Ensures smooth display on small devices and scales up to desktop.
* **Navigation Bar:** Sticky, responsive navigation for easy access to all pages.
* **Color Scheme & Typography:** Chosen for readability, modern look, and brand alignment.
* **Accessibility:** Semantic HTML, ARIA labels, focus indicators, and keyboard navigation support.

---

## ⚙️ Technical Details

* **Responsive Design:** Implemented using media queries, flexible grids, and relative units.
* **Form Validation:** JavaScript validates name, email, and message fields before submission.
* **Performance Optimization:**

  * Images compressed and resized
  * Minified CSS and JS
* **Cross-Browser Compatibility:** Tested on Chrome, Firefox, Edge, and Safari.
* **Deployment:** Hosted on GitHub Pages/Netlify with proper directory structure.

---

## 🧪 Testing Evidence

* **Responsiveness:** Tested on multiple devices (mobile, tablet, desktop)
* **Form Validation:**

  * Empty fields show error messages
  * Invalid email format triggers alert
